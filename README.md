# Employee_salary_Analysis_using_Numpy
An Employee Salary Analysis System built using Python and NumPy. It analyzes employee salaries, calculates statistical measures, identifies highest and lowest-paid employees, performs department-wise analysis, ranks employees, and generates a comprehensive salary report.
The project takes employee details as input and performs various numerical calculations and data analysis operations using NumPy.

🚀 Features

* Collect employee details (Name, ID, Department, and Salary).
* Calculate total salary expenditure.
* Calculate average and median salary.
* Identify the highest-paid and lowest-paid employees.
* Find employees earning above the average salary.
* Rank employees according to their salaries.
* Calculate department-wise average salaries.
* Identify employees earning above ₹40,000 and below ₹30,000.
* Calculate annual salaries of employees.
* Calculate salary standard deviation and variance.
* Generate a final employee salary analysis report.
